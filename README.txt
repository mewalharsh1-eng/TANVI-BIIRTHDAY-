BIRTHDAY WEBSITE — HOW TO RUN

1. Keep index.html, style.css and script.js together in the same folder.
2. Put your original photo/video files in a folder named Image (capital I), and your song in Music/Zindagi_Di_Paudi_Blessed_1.mp3.
3. Open index.html in a browser. For best results, use VS Code + Live Server.

Asset note: The ZIP includes the complete website code, but your personal Image/ and Music/ files were not included because they were not available as the actual named asset files in this upload. If a filename is missing, that specific photo/video/song will not play.
